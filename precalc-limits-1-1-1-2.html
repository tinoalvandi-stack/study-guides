One-page decision tree

A limit asks one question: what y-value does f(x) approach as x gets close to c, with x ≠ c? The answer is always a y-value.

Read the direction→ left only right onlyno sign = both sides

Given a graph

  • Ride the curve toward x = c from each side you need. Read the y-value you approach.
  • Ignore the dot at x = c. That is f(c), not the limit.
  • Sides match → that y. Sides differ → does not exist.
  • Both sides shoot up → ; both down → ; one up, one down → does not exist.

Given a table

  • Read y as x closes in on c from each side (like 1.99, 1.999 and 2.01, 2.001).
  • Round to the thousandths. Same value both sides → that is your estimate.
  • Different finite sampled or rounded values alone do not establish DNE. If the left and right trends approach different values, the table suggests the two-sided limit does not exist.
  • A table only estimates. It never proves.

Piecewise, c at a break

Find each one-sided limit with the piece that lives on that side. Equal → that value. Unequal → does not exist.

How to write it (graded on notation)

  • Write lim on every line until the line where you substitute. That line drops it.
  • Never write "= 0/0". Say "substitution produces 0/0" in your head or in words, then keep working.
  • Write " does not exist." No "= DNE", and no bare "DNE" with no limit named.
  • Infinite limit: write or . It says which way f(x) grows without bound; it is not a finite limit.
  • Difference quotient: put f(x + h) in parentheses, distribute the minus sign, substitute 0 for h, not for x.

Limit vs. function value, on a graph

The limit cares about the points near c. The function value f(c) is the one point at c. They can match, differ, or one can exist without the other.

No holeLimit = f(c). Both exist and agree.
Hole, dot elsewhereLimit is the hole's height. f(c) is the dot. They differ.
Hole, no dotLimit still exists. f(c) does not exist.

Far left and far right, a graph that levels off along a horizontal line has a horizontal asymptote there: the y-value it approaches as or . A vertical asymptote is where the graph runs up or down along a vertical line.

Write a vertical asymptote as x = a when at least one one-sided limit at a is ∞ or −∞; record each side separately. Write a horizontal asymptote as y = L when limx→∞ f(x) = L or limx→−∞ f(x) = L for finite L. A tail that grows without bound has no horizontal asymptote on that end.

Graph traps

  • "All values of a where ": find every x where the curve reaches height 3 from both sides. A spot reached from only one side does not count. A lone isolated point never counts.
  • Open interval: its endpoints are not in the question, so they cannot be answers.
  • Endpoints of a graph: if the graph starts at x = 1, only the side that exists can be used.
  • A mixed-in "find f(6)" is a function value: use the filled dot, not the open circle.

Editable tables and limits at infinity

On an editable table, sample near a finite c from the requested side: c − 0.1, c − 0.01, c − 0.001 on the left, and c + 0.1, c + 0.01, c + 0.001 on the right. Check f(c) separately if asked; its value or an undefined entry at c does not decide the limit. Given quiz tables require reading these trends, not calculating new entries.

For x → −∞, try increasingly negative values such as −10, −100, −1000. For x → ∞, try 10, 100, 1000. Inspect the two ends separately: they can approach different heights. Infinity is not a real input, so never enter “∞” as an x-value.

Why a table cannot prove a limit

A table shows a handful of points. The function could do something different between them or even closer to c. Read it as "appears to be," then confirm with algebra when you have the formula. Different finite sampled or rounded values alone do not establish DNE. If the left and right trends approach different values, the table suggests the two-sided limit does not exist.

Substitute first. For a polynomial, or a rational, root or trig expression with c in its domain, that is the whole job.

When an inner fraction is undefined

An undefined fraction inside a larger expression does not by itself decide the limit. Simplify the whole expression on nearby points before classifying it.

Original mini-example:

limx→2 (x + 3) / [1/(x − 2) − 1]
The inner fraction is undefined at 2; that is not yet the answer.
= limx→2 [(x + 3)(x − 2)] / [1 − (x − 2)]
For x ≠ 2 near 2, multiply the entire numerator and denominator by x − 2.
= limx→2 [(x + 3)(x − 2)] / (3 − x)
Simplify the denominator; its limit is 1, not 0.
= [(2 + 3)(2 − 2)] / (3 − 2) = 0
