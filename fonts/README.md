# Fonts

Self-hosted. The site's CSP allows `font-src 'self'` only, so nothing is loaded from a font CDN.

| File | Family | Used by | License |
| --- | --- | --- | --- |
| `source-serif-4-latin.woff2`, `source-serif-4-greek.woff2` | Source Serif 4 (variable weight 200–900) | headings on the guides, homepage and class pages | SIL Open Font License 1.1, `OFL-source-serif-4.txt` |
| `source-sans-3-latin.woff2`, `source-sans-3-latin-italic.woff2`, `source-sans-3-greek.woff2` | Source Sans 3 (variable weight 200–900) | body text and interface | SIL Open Font License 1.1, `OFL-source-sans-3.txt` |
| `figtree*.woff2`, `bricolage-grotesque.woff2`, `eb-garamond-*.woff2`, `oswald.woff2`, `Rye-Regular.woff2` | older faces | pages that keep their own layouts (cram sheets, jeopardy, 404) | SIL Open Font License 1.1 |

Source Serif 4 and Source Sans 3 are by Adobe. Copyright 2014–2023 Adobe (Source Serif) and 2010–2024 Adobe (Source Sans), with Reserved Font Name "Source". The license files are copied unchanged from the `adobe-fonts/source-serif` and `adobe-fonts/source-sans` repositories. The woff2 files are the unmodified latin and greek subsets published by Fontsource (`@fontsource-variable/source-serif-4` and `@fontsource-variable/source-sans-3`, version 5.3.0), which repackage the Google Fonts builds.
